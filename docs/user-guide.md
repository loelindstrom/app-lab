# Using App Lab

Using App Lab is simple: open the link below and click around.

[Open App Lab](https://loelindstrom.github.io/app-lab/)

Need inspiration? Here is a quick walkthrough of what you can do. It is as easy as 1, 2, 3.

## 🚀 Create Your First App

1. Select the **+** button in the bottom-right corner. App Lab opens an example app.
2. Select **BuilderAI** to turn it into something new. Choose either:
   - **Copy prompt + code:** Paste it into your favorite AI tool and finish with something like: “Rewrite this as a rubber-duck
     app with a cyberpunk theme.” Paste the returned HTML into **Source (`<>`)** and select **Save**.
   - **Built-in AI:** After connecting AI from the settings wheel in the top-right corner, ask BuilderAI to edit the app directly.
3. Select the back arrow in the top-left corner. Create another app, or delete this one if the rubber duck did not work out.

## 🤝 Share Your App With Friends

1. Open the settings wheel in the top-right corner and follow the instructions for connecting a Firebase Realtime Database.
2. Select **Share** and send the link to a friend. You can both edit the source and update app data live. Keep a backup if you do
   not trust your friends' coding skills.
3. Since Firebase is connected, you can also restore and sync your whole workspace on another device from **Settings > Sync
   device**.

## 🛠️ Contribute To App Lab

1. Well done exploring the app.
2. You have probably noticed something that could be improved.
3. Read, or let your AI agent read, the [developer guide](./README.md), then start contributing code to the repository.
