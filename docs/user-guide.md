# Using App Lab

Using App Lab is simple: open the link below and click around.

[Open App Lab](https://loelindstrom.github.io/app-lab/)

Need inspiration? Here is a quick walkthrough of what you can do. It is as easy as 1, 2, 3.

## 🚀 Create Your First App

1. Select **+** in the bottom-right corner, optionally name the app, then select **Create app**.
2. Open the sparkle button in the top-right corner. Under **AI**, choose either:
   - **External:** Describe the change, such as “_Rewrite this as a rubber-duck app with a cyberpunk theme._” Select **Copy prompt + code**, paste it into your favorite AI, then paste its HTML reply back and select **Apply code**.
   - **Chat:** Connect your AI from launcher settings, then describe the changes directly in App Lab.
3. Select the back arrow in the top-left corner. Create another app, or delete this one if the rubber duck didn't tickle your nerve.

## 🤜🤛 Share Your App With Friends

1. Open the settings wheel in the top-right corner and follow the instructions under **Storage** > **First-time setup** (don't forget those security steps!).
2. In an app, open the sparkle button, select **Share**, and create a share link. You can both edit the source and update app data live. So better keep a backup if you don't trust your friends' coding skills ;).
3. Since Firebase is connected, you can also restore and sync your whole workspace on another device from settings: **Storage > Sync
   device**.

## 🛠️ Contribute To App Lab

1. Well done exploring the app.
2. You have probably noticed something that could be improved, who's perfect in the end right?
3. Read, or let your AI agent read, the [developer guide](./README.md), then start contributing code to the repository!
